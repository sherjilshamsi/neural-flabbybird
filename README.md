# Neural Flappy Bird

A Java implementation of Flappy Bird with AI control using neural networks.

## Requirements
- Java 17 or higher
- Maven 3.6 or higher

## Setup Instructions

1. Clone the repository
2. Build the project:
   ```bash
   mvn clean install
   ```
3. Run the game:
   ```bash
   mvn javafx:run
   ```

## Project Structure
- `src/main/java/com/flappybird/`
  - `Main.java` - Application entry point
  - `game/` - Game logic and components
  - `ai/` - Neural network implementation
  - `ui/` - User interface components

## Features
- Classic Flappy Bird gameplay
- AI-controlled bird using neural networks
- Training mode for the AI
- Visual representation of the neural network
